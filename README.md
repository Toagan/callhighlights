# Call Highlights

A simple web app to format and display call transcripts from Notion meetings in a clean, Notion-inspired interface.

## Features

- Paste call transcripts from Notion
- Clean, minimal Notion-like design
- Preserves formatting and line breaks
- Works offline - no dependencies

## Usage

1. Open `index.html` in your browser
2. Paste your Notion call transcript into the textarea
3. Click "Display" to see the formatted transcript

## Files

- `index.html` - Main HTML file
- `styles.css` - Styling
- `script.js` - JavaScript functionality

## Design

Inspired by Notion's clean aesthetic with:
- Light gray background (#f7f6f3)
- Clean typography
- Generous spacing
- Simple, focused interface

## Local Development

Simply open `index.html` in your browser - no build process or server required.
