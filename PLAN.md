# Call Highlights Web App - Plan

## Overview
Simple web app: paste Notion call transcripts, see them formatted in a clean Notion-like style.

## Files
- `index.html` - Main page
- `styles.css` - Styling
- `script.js` - Functionality

## Features
1. **Textarea** - Paste transcript here
2. **Display area** - Shows formatted transcript below
3. **One button** - "Display" to show the transcript

## Design (Notion-inspired)
- Background: Light gray/white (`#f7f6f3`)
- Text: Dark gray (`#37352f`)
- Centered layout, max-width ~800px
- Clean typography, generous spacing
- Preserve line breaks

## How it works
1. User pastes transcript into textarea
2. Clicks "Display" button
3. Transcript appears formatted below
4. That's it!

## Technical
- Vanilla HTML, CSS, JavaScript only
- No frameworks or build tools
- Preserve line breaks when displaying
